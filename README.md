# Lexsy AI Legal Document Filler

Mono-repo containing:

- **/frontend** — Next.js 14 (App Router, TS, Tailwind)
- **/backend** — FastAPI (Python 3.11)

## Quick Start

1. See `/frontend/README.md` for UI setup and dev commands.
2. See `/backend/README.md` for API setup and dev commands.

## Deploy

- Frontend: Vercel (Free)
- Backend: Render (Free)

## Environment

- `NEXT_PUBLIC_API_URL` (frontend) → your Render backend URL
- `OPENAI_API_KEY` (backend) → OpenAI key in Render env
