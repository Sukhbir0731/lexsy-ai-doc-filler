# Frontend (Next.js 14)

## Stack

- Next.js 14 (App Router) + React + TypeScript
- TailwindCSS
- axios, react-hook-form, @headlessui/react

## Dev

1. Install Node 18+.
2. `npm install`
3. `npm run dev` → http://localhost:3000

## Env

Create `.env.local`:

- NEXT_PUBLIC_API_URL = http://localhost:8000

## Build

- `npm run build` → `.next/`
- `npm start`
